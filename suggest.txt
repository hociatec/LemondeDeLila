STANDARDS ET CONVENTIONS

NAMING CONVENTIONS (À appliquer partout)
- Services principaux : [Game]GameService (ex: DameNatureGameService)
- Services domaine : [Game][Domain]Service (ex: DameNaturePollutionService)
- Métadonnées : [Game]Metadata (ex: DameNatureMetadata)
- Constantes : [GAME]_[CONCEPT] (ex: DAME_NATURE_PHASES)
- Handlers d'actions : [Action]ActionHandler (ex: DrawActionHandler)
- Tests : [fichier].spec.ts (unitaires), [fichier].scenario.spec.ts (intégration)

STRUCTURE DE DOSSIERS (À respecter pour tous les jeux)
```
game-name/
├── actions/               # Handlers d'actions
├── bots/                  # Stratégies IA
├── definitions/           # Configurations statiques
├── model/                 # Types et entités
│   └── content/           # Fichiers JSON
├── phases/                # Gestion des phases
├── presenter/             # Exposition d'état
├── rulebook/              # Validation
├── setup/                 # Initialisation
├── tests/                 # Tests
├── [game].module.ts
├── [game].service.ts
└── README.md
```
