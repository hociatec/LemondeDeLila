# Course des étoiles

Pour 2 à 4 joueurs. Chaque joueur commence sur la case zéro, sans étoile.
Le premier joueur de la table commence ; les joueurs jouent ensuite dans
l'ordre de la table.

À votre tour, choisissez **Avancer** : vous avancez d'une case, recevez une
étoile et passez la main. Le premier joueur à obtenir trois étoiles remporte
immédiatement la partie.

Ce jeu d'initiation, sans hasard, sert aussi de référence pour le format
déclaratif du moteur. Toute sa logique est décrite dans `game.json`.
