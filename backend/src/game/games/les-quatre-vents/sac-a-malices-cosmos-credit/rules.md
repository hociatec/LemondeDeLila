# Sac à Malices — Cosmos & Crédit

Variante « Cosmos & Crédit » (Cosmopoly).

- Déplacements : 2d6, doubles = rejouer (3 doubles consécutifs = prison).
- Achat/loyers : planètes / stations (économie simplifiée).
- Cartes : Anomalie Spatiale (Chance) / Événement Spatial (Communauté).
- Prison : attente (double pour sortir), sans amende.
- Parking : neutre (pas de pot).
