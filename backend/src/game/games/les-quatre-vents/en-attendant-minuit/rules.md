# En Attendant Minuit !

## Objectif
Atteindre exactement la case 56 (Minuit). En cas de dépassement, vous avancez jusqu’à 56 puis reculez du surplus.

## Matériel
- Un plateau de 56 cases
- Un dé (1d6)
- 60 cartes (pioche unique)

## Déroulement d’un tour
1. Le joueur lance le dé.
2. Il avance du nombre indiqué.
3. Il applique l’effet de la case :
   - Case “Carte Noël” : pioche une carte et résout son effet.
   - Case “Avance/Recule/Passe ton tour/Événement” : applique l’effet de la case.
   - Case neutre : rien de spécial.

## Règles spéciales
- Si vous arrivez sur une case déjà occupée, vous reculez d’une case.
- Certaines cartes accordent une protection (“ignorez le prochain malus” / “ignorez la prochaine case passe-ton-tour”) : l’effet reste actif jusqu’à son déclenchement.
