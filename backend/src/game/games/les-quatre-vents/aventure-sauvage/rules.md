# Aventure Sauvage

Jeu de course sur un plateau de 30 cases.

- À votre tour : lancez le dé et avancez.
- Case verte : rien.
- Case rouge : appuyez sur **Espace** pour piocher une carte **Animal rigolo**.
- Case jaune : appuyez sur **Espace** pour piocher une carte **Coup de patte**.
- La carte piochée et son effet sont annoncés avant leur résolution.
- Arrivée : première personne à atteindre la mare.
