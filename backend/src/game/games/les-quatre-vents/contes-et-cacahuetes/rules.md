# Contes et cacahuètes !

- Objectif : être le premier à atteindre (ou dépasser) la case Arrivée (60).
- Dé : 1d6, déplacement puis effet de la case.
- Cases : Conte / Bonus / Malus / Surprise.
- Les cartes s'appliquent immédiatement ; certaines posent des effets temporaires (protection, inversion, etc.).

## Raccourcis de consultation

- P : votre position uniquement.
- Maj+P : les positions de tous les joueurs.
- S : le classement de la course, du plus avancé au moins avancé, avec le nombre de cases restant avant l'arrivée. Les joueurs à égalité partagent le même rang.
