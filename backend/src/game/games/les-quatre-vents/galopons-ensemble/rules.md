# Galopons ensemble !

## Objectif
Atteindre l'écurie finale avec au moins 3 pommes.

## Matériel
- Un plateau (40 cases)
- Un dé (1d6)
- 30 cartes Aventure Équestre

## Déroulement d'un tour
1. Le joueur lance le dé.
2. Il avance du nombre indiqué.
   - La case finale doit être atteinte exactement.
   - Si le lancer dépasse la case finale, le pion recule du nombre de cases en trop.
3. Effet de case :
   - Fer à cheval : pioche une carte Aventure et résout l'effet.
   - Bonus : gagne des pommes.
4. Si un joueur arrive exactement sur la case d'un autre joueur, l'autre recule de 5 cases.

## Fin de partie
Quand un joueur atteint l'écurie finale, il reçoit 1 pomme.

- S'il a alors au moins 3 pommes, il remporte immédiatement la partie.
- Sinon, son pion repart en sens inverse vers la case départ.
- Une fois la case départ atteinte, le pion repart dans le sens normal jusqu'à l'écurie finale.
