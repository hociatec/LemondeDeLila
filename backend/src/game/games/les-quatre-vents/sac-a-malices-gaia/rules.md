# Sac à Malices — Gaïa

Variante « Gaïa » (Monopoly écolo).

- Déplacements : 2d6, doubles = rejouer (3 doubles consécutifs = prison).
- Achat/loyers : projets écologiques (économie simplifiée).
- Cartes : Chance / Communauté.
- Prison : sortie par amende ou carte (selon règles de la variante).
- Parking : neutre (pas de pot).
