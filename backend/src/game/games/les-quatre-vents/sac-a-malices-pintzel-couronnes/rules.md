# Sac à Malices — Pintzel & Couronnes

Variante « Pintzel & Couronnes » (plateau strasbourgeois).

- Déplacements : 2d6, doubles = rejouer (3 doubles consécutifs = prison).
- Achat/loyers : propriétés, gares, compagnies.
- Constructions : maisons / hôtel sur un groupe complet.
- Cartes : Chance / Caisse de communauté.
- Parc Gratuit : récupère le pot (taxes).
- Prison : 3 tours max, sortie par amende/carte (selon règles de la variante).
