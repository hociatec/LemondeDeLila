# Panier Express - Règles (résumé)

- Objectif : compléter sa liste de 5 produits puis revenir sur la case départ.
- Tour :
  1. Lancer le dé (`roll`).
  2. Avancer du nombre indiqué.
  3. Résoudre la case : stand (piocher une carte Courses), événement, échange, quiz.
  4. Passer au joueur suivant (sauf si skip).
- Victoire : panier contient tous les items de la liste et pion pile sur la case départ.
