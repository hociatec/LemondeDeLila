# Course JSON

Deux à quatre joueurs reçoivent chacun une carte et commencent en case zéro,
sans étoile. À son tour, un joueur avance d'une case et gagne une étoile.
Le premier à obtenir trois étoiles remporte la partie.

Ce paquet de référence ne contient aucun TypeScript spécifique. Il est exécuté
par les tests du compilateur JSON et reste hors du catalogue de production.
