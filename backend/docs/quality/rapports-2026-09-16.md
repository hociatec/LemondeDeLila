## Limites conservées explicitement

- Pas de clôture automatique des rapports : les chansons spécifiques du Morpion
  restent à identifier. Le suivi ci-dessous traite la commande S dans Contes.
- Les parcours de focus et le comportement NVDA doivent être confirmés sur le
  client Windows. Aucun envoi de message privé de test aux vrais utilisateurs.
- Les tests reproduisent les scénarios décrits ; ils ne garantissent pas que
  toutes les anciennes parties sauvegardées reproduisent exactement ces états.
