# Attestation de revue indépendante des contrôles

Ce document est rempli dans une pull request par une personne qui n'est ni
l'auteur des changements contrôlés ni l'auteur de la dernière révision des
auditeurs. La protection de `main` impose son approbation après le dernier push.

- Date UTC :
- Réviseuse ou réviseur (nom et compte GitHub) :
- Commit examiné :
- Campagne `npm run mutation:test` (rapport joint) :
- Auditeurs examinés : architecture, structure, persistance, sécurité,
  ordonnancement, observabilité et gouvernance.
- Exceptions examinées et justification :
- Mutations survivantes : aucune / liste et décision documentée.
- Conclusion : approuvé / refusé.
- Signature Git (`git show --show-signature COMMIT`) :

Une attestation vide, signée par l'auteur ou portant sur un commit antérieur au
dernier push ne satisfait pas le contrôle.
