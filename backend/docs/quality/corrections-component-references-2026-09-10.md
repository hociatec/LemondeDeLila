# Références de composants — point 30 clôturé

La compilation d'une définition valide les références avant le démarrage d'une
partie. Le contrôle couvre les cartes installées ou non, les effets imbriqués,
les pistes et leurs cases, les ressources, les marchés, les inventaires, les
mains et les ensembles de cartes. Les références d'initialisation sont aussi
contrôlées.

Preuves : `game-definition-component-validator.ts`,
`component-initialization-references.ts`, `static-effect-references.ts`,
`component-reference-validation.spec.ts` et `static-effect-references.spec.ts`.
