# Morpion

## But
Aligner 3 symboles (horizontal, vertical ou diagonal) sur une grille **3×3**.

## Déroulement
- 2 joueurs.
- À tour de rôle, placez votre symbole sur une case vide.
- La partie se termine quand :
  - un joueur aligne 3 symboles, ou
  - toutes les cases sont remplies (match nul).

## Commandes
- Flèches : déplacer le focus sur la grille.
- Entrée : jouer sur la case focus.
