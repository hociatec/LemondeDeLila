# A fond les ballons !

- Avant la partie, chaque joueur choisit un pion : Capitaine Cacahuète, Professeur Gribouille, Miss Froufrou, Sir Croquou, Chinchillator 3000, Hamstéro Dynamite.
- Objectif : atteindre exactement la case 40 (Grosse Noix Dorée).
- Dé : 1d6, déplacement immédiat puis effet de case.
- Si vous dépassez la case 40, vous reculez du nombre de pas en trop.
- Cases spéciales : Folie (carte Loufoque), Bonus (+2), Piège (-2), Glissade (±1..3 aléatoire), Tornade (échange de place), Chaton (retour départ).
