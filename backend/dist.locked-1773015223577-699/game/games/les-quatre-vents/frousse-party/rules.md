# Frousse Party !

## Objectif
Être le premier joueur à atteindre (ou dépasser) la case 50 (sortie du manoir).

## Matériel
- Un plateau de 50 cases
- Un dé (1d6)
- 60 cartes réparties en catégories : Pièges, Farces, Fantômes, Bonus

## Déroulement d’un tour
1. Le joueur lance le dé.
2. Il avance du nombre indiqué.
3. S’il arrive sur une case “symbole”, il pioche une carte et applique son effet immédiatement.
4. Le tour passe au joueur suivant (sauf effet “rejoue”).
