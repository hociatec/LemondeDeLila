Suivi des évolutions

Historique synthétique des ajouts réalisés dans l’application Le Monde de Lila durant la session en cours.

1. Script et outillage

État initial
  • Lecture et compréhension de start-lila.ps1 pour automatiser Maven, Symfony (HTTP + WebSocket) et le client Swing.
  • Vérification des dépendances locales (PHP, Java, composer) et des répertoires nécessaires (backend, java-client, logs).

2. Cycle d’authentification

Étapes successives
  • fix Résolution du StackOverflowError dû au HomeScreen (recours à computeIfAbsent).
  • feature Alignement complet avec l’API Symfony :
    • Login → /api/login renvoie désormais le JWT, stocké côté client dans ClientSession.
    • Inscription → collecte de l’e-mail et envoi à /api/register.
  • feature Refonte du formulaire d’accueil : navigation par cartes (accueil, connexion, inscription), Alt+C / Alt+I pour choisir, Alt+R pour revenir.
  • feature Ajout d’un menu principal après connexion (Étagères, Rejoindre une table, Tchat, Options).

3. Options et préférences

  • feature Création d’AppSettings et AppSettingsService pour persister les préférences utilisateur (config/settings.json).
  • feature Boîte Options :
    • Volumes jeu et musique.
    • Confirmation à la fermeture de l’application.
    • Activation / désactivation du tchat.
    • Confirmation à la fermeture du tchat.
  • fix Fermeture contrôlée de l’app : AppLauncher installe un listener qui consulte les préférences (confirmations, etc.).
  • fix Correction du Recursive update lors de l’arrêt en mémorisant les instances NarrationQueue/ScreenReaderAnnouncer.

4. Tchat en temps réel

  • feature Implémentation complète du tchat :
    • Connexion WebSocket via ChatConnectionFactory, prise en charge du token JWT (déduit de ClientSession), endpoint configurable (network.ws.presence).
    • Gestion de l’historique, des messages temps réel et des états de connexion.
    • Fenêtre Swing (ChatWindow) accessible depuis le menu, envoi avec Entrée, Shift+Entrée pour les retours à la ligne.
    • Historique formaté avec ligne blanche finale pour une lecture claire.
  • feature Règles métier :
    • Tchat accessible seulement si l’utilisateur est authentifié et si l’option est activée.
    • Possibilité de demander confirmation lors de la fermeture de la fenêtre tchat.
  • fix Ajustement des URLs WS : ajout de network.ws.presence dans client.properties (correspond à app.ws côté Symfony).

5. Documentation

  • doc docs/framework-guide.html (lancement, architecture, modules, raccourcis, API, options, tchat).
  • doc docs/suivi.html (ce fichier) : récapitulatif chronologique des travaux pour garder une base de référence.

6. Module Nemesis

Mise a jour recente
  • feature Renommage complet des classes MissionNemesis* en Nemesis* (controleur, services, modeles, vues Swing).
  • fix NemesisSessionStore delegue maintenant a InMemoryGameSessionStore, evitant l'heritage d'une classe final.
  • doc Mise a jour de framework-guide.html et de ce suivi pour decrire la nouvelle structure.
  • fix client.properties aligne sur ws://127.0.0.1:8081/ws, coherent avec app:realtime:serve.
  • fix start-lila.ps1 attend l'ouverture du port WebSocket avant de lancer le client Swing.
  • feature Ajout d'un TokenAwareRealtimeGateway qui ajoute automatiquement le JWT aux connexions WS et ne se connecte qu'apres authentification.

7. Prochaines pistes

  • Brancher le menu “Étagères” / “Rejoindre une table” sur les API Symfony correspondantes.
  • Intégrer une vraie UI de présence (liste des joueurs connectés) basée sur les messages presence-update.
  • Ajouter des tests Swing ou des scripts e2e pour valider les flux critiques (connexion, tchat, options).

8. Architecture client

Refonte structurelle
  • feature Regroupement des sources Java par domaines (chat, user, catalogue, game, presence, settings) : chaque dossier embarque désormais ses controller, model, service, view et événements spécifiques.
  • feature Migration du framework applicatif sous com.lemondelila.client.framework pour conserver une arborescence unique et cohérente côté client.
  • feature Création d’un espace com.lemondelila.client.application accueillant les vues transverses (accueil, menu, boîtes de dialogue, raccourcis) et leurs artefacts (controller, service, etc.).
  • feature Modules d’initialisation rangés dans leur domaine (ChatModule, CatalogueModule, SettingsModule, etc.) et orchestration centralisée via ApplicationModule.
  • doc Mise à jour du guide framework pour présenter l’arborescence domaine et clarifier les points d’entrée.
